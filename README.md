Strona główna i sprzedażowa dla aplikacji **Kursy**.

- domena docelowa: `tyli.pl`
- aplikacja Kursy: osobne repozytorium `Tyliszczak/Kursy`

To repozytorium zawiera wyłącznie stronę informacyjną/sprzedażową. Kod aplikacji nie powinien być tutaj umieszczany.
